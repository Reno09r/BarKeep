# BarKeep

Менеджер иконок меню-бара macOS в духе Bartender/Ice: прячет иконки за край экрана,
показывает их в панели под меню-баром, ищет по названиям и умеет возвращать всё назад
одной горячей клавишей.

Написан с нуля на Swift/AppKit + SwiftUI. Ice использовался только как источник
идей о поведении меню-бара; его код (GPL-3.0) не копировался.

## Что уже работает

- **Скрытие иконок** раздуванием разделителя-статус-элемента до 10 000 px:
  всё, что левее разделителя, уезжает за край экрана.
- **Три статус-элемента BarKeep**: управляющая иконка, разделитель скрытых и
  (неактивный) разделитель всегда-скрытых.
- **Панель под меню-баром** (ЛКМ по иконке BarKeep): снимки скрытых иконок,
  поиск по названию, Enter активирует первый результат, Esc/клик вне — закрыть.
- **Активация скрытой иконки** из панели: секция временно показывается,
  иконка нажимается через Accessibility (`AXPress`), затем секция прячется обратно.
- **Показ при наведении**: наведите курсор на пустую часть меню-бара левее
  видимых иконок — скрытые появятся на месте; уберите курсор — спрячутся.
- **Глобальные горячие клавиши** через Carbon `RegisterEventHotKey`.
- **Восстановление иконок** при выходе и аварийный сброс.
- **Онбординг разрешений** (Accessibility + запись экрана) и отчёт для диагностики.
- **Само-подпись** стабильным сертификатом, чтобы TCC-разрешения не сбрасывались
  после пересборки.

## Требования

- macOS 14+ (проверено на macOS 15.8.1, Apple Silicon).
- Xcode 15+ и [XcodeGen](https://github.com/yonaskolb/XcodeGen) (`brew install xcodegen`).
- Свободный Apple ID не обязателен: используется локальный само-подписанный сертификат.

## Сборка и запуск

```bash
make signing   # один раз: создать локальный сертификат "BarKeep Dev"
make gen       # сгенерировать BarKeep.xcodeproj из project.yml
make build
make run       # запустить приложение
make logs      # хвост ~/Library/Logs/BarKeep.log
make stop      # SIGTERM (иконки восстановятся при следующем запуске)
```

`make build` подписывает приложение сертификатом `BarKeep Dev` из отдельной
связки ключей `~/Library/Keychains/barkeep-dev.keychain-db` (пароль `barkeep`).
Ad-hoc подпись (`CODE_SIGN_IDENTITY="-"`) тоже собирается, но после каждой
пересборки macOS считает приложение новым и сбрасывает Accessibility/запись экрана.

Полная команда сборки, если не используется Makefile:

```bash
xcodegen generate
xcodebuild -project BarKeep.xcodeproj -scheme BarKeep -configuration Debug \
  -derivedDataPath build \
  CODE_SIGN_STYLE=Manual CODE_SIGN_IDENTITY="BarKeep Dev" \
  OTHER_CODE_SIGN_FLAGS="--keychain $HOME/Library/Keychains/barkeep-dev.keychain-db" build
```

## Разрешения

При первом запуске BarKeep попросит:

1. **Универсальный доступ (Accessibility)** — сканирование и нажатие чужих иконок.
2. **Запись экрана (Screen Recording)** — снимки иконок для панели.

Выдайте оба в «Системные настройки → Конфиденциальность и безопасность».
После выдачи перезапустите приложение.

Важно: приложение, запущенное из терминала, наследует разрешения терминала.
Для честной проверки запускайте через Finder/`open` и выдавайте разрешения
именно `BarKeep.app` (подпись `com.reno.barkeep`).

## Горячие клавиши

| Комбинация | Действие |
|---|---|
| `⌃⌥⌘H` | показать/скрыть секцию «Скрытые» |
| `⌃⌥⌘A` | показать/скрыть «Всегда скрытые» (секция пока выключена) |
| `⌃⌥⌘R` | аварийно вернуть все иконки на место |

ЛКМ по иконке BarKeep — панель, ПКМ/`⌃`+ЛКМ — меню.

## Как устроены секции

Разделитель — обычный `NSStatusItem` с тонкой вертикальной чертой. Пока он
обычной ширины, иконки слева от него видны. Когда BarKeep «прячет» секцию,
разделитель растягивается до 10 000 px и уводит всё левее за край экрана.

Секция определяется позицией: иконки **правее** разделителя считаются
видимыми, **левее** — скрытыми. По умолчанию справа остаются ~4 иконки,
остальные скрыты.

Чтобы изменить границу:

1. Покажите скрытые (`⌃⌥⌘H` или панель).
2. С зажатым `⌘` перетащите тонкую черту-разделитель в меню-баре влево/вправо.
   Позиция запоминается системой.
3. Снова скройте секцию.

Так же с `⌘` можно перетаскивать сами иконки через разделитель — какие
оказались справа, те и останутся видимыми.

## Панель

- Открывается по ЛКМ на иконке BarKeep или из меню.
- Показывает все иконки, которые сейчас не в видимой секции.
- Поиск фильтрует по отображаемому имени; работает по-русски и по-английски
  («телеграм» находит Telegram, «telegram» — Телеграм), Enter открывает первый
  результат. Поле получает клавиатурный фокус сразу при открытии панели.
- Ряд иконок прокручивается колесом мыши (вертикальное колесо двигает его
  по горизонтали) и трекпадом; при поиске лишние иконки скрываются.
- Клик по иконке: панель закрывается, секция временно показывается,
  иконка нажимается через `AXPress`, через ~6 секунд секция прячется.
- ПКМ по иконке — контекстное меню: «Активировать», «Скрыть <приложение>»,
  «Завершить <приложение>…» и «Завершить принудительно…». Перед завершением
  показывается подтверждение; для системных приложений (`com.apple.*`),
  самой BarKeep и иконок без процесса пункты завершения отключены.
- Клик вне панели или Esc закрывает её; фокус возвращается приложению,
  которое было активным до открытия панели (кроме активации иконки).

## CLI

Бинарник понимает отладочные режимы (удобно для автоматизации):

```bash
BarKeep --scan                 # список иконок: позиция, размер, AX, pid, bundle id
BarKeep --press "Пункт управления"   # AXPress по имени
BarKeep --send showHidden      # показать скрытые
BarKeep --send hideHidden      # спрятать скрытые
BarKeep --send reset           # вернуть все иконки
BarKeep --send panel           # открыть/закрыть панель
BarKeep --send "activate:Telegram"   # временно показать и нажать иконку
```

## Ограничения и планы

- **Перемещение чужих иконок программно** пока не реализовано. macOS игнорирует
  обычные синтетические ⌘-drag события для элементов меню-бара; Ice решает это
  через `postToPid` + event tap + «scrambling» событий. Поэтому распределение
  иконок по секциям сейчас позиционное и настраивается вручную (`⌘`-drag).
- **Секция «Всегда скрытые»** присутствует в модели, но выключена: без
  перемещения иконок её нельзя наполнить. Включается после реализации mover'а.
- **Правила по приложениям и профили (работа/дом)** запланированы; им нужен
  тот же mover, чтобы менять секцию иконки.
- **Автозапуск при входе** пока не реализован — добавьте BarKeep в
  «Системные настройки → Основные → Элементы входа» вручную.
- Не запускайте два экземпляра BarKeep одновременно — это вызывает «дрейф»
  разделителей. Если приложение было убито через `SIGKILL`, при следующем
  запуске раскладка нормализуется.
- Не держите одновременно Ice и другой менеджер меню-бара: они конфликтуют
  за разделители. BarKeep предупреждает об этом в меню.

## Диагностика

- Журнал: `~/Library/Logs/BarKeep.log` (меню → «Открыть журнал»).
- Меню → «Скопировать отчёт в буфер» — снимок состояния иконок и разделителей.
- Аварийный возврат иконок: `⌃⌥⌘R`, меню → «Вернуть все иконки», либо
  `BarKeep --send reset`.
- Если меню-бар выглядит «съехавшим», завершите все экземпляры BarKeep и
  запустите один заново.
