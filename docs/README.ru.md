## Обзор

**BarKeep** — это open-source менеджер меню-бара macOS в духе Bartender и Ice. Он прячет лишние иконки за край экрана, предоставляет быстрый доступ к скрытым элементам через плавающую панель под меню-баром, поддерживает моментальный поиск на нескольких языках, автоматически разворачивает иконки при наведении курсора и позволяет вернуть все элементы назад одной аварийной горячей клавишей.

Приложение полностью написано на **Swift, AppKit и SwiftUI** без сторонних зависимостей. Исходный код Ice (GPL-3.0) не копировался; все механизмы спроектированы и реализованы с чистого листа.

## Возможности

- **Скрытие иконок за край экрана**: Раздувание разделителя-статус-элемента до 10 000 px плавно сдвигает все иконки левее за границу дисплея.
- **Плавающая панель Bar Panel** (*ЛКМ* по иконке BarKeep): Стильное HUD-окно под строкой меню со снимками скрытых иконок и горизонтальной прокруткой трекпадом или колесом мыши.
- **Многоязычный поиск**: Моментальный поиск приложений с поддержкой транслитерации (например, запрос на кириллице или казахском находит латинские имена приложений). Нажатие `Enter` активирует первый результат, `Esc` или клик вне панели закрывают её.
- **Нативная активация скрытых иконок**: Клик по иконке в панели временно отображает соответствующую секцию меню-бара, выполняет `AXPress` через Accessibility API и аккуратно прячет секцию обратно.
- **Показ при наведении**: Наведите курсор на пустое пространство строки меню — скрытые иконки плавно развернутся; уведите курсор — спрячутся обратно.
- **Контекстное меню управления приложениями**: Правый клик по иконке в панели позволяет активировать, скрыть, корректно завершить или принудительно закрыть приложение (с подтверждением для сторонних программ).
- **Глобальные горячие клавиши**: Обработка через Carbon `RegisterEventHotKey`:
  - `⌃⌥⌘H` — Показать/скрыть секцию «Скрытые»
  - `⌃⌥⌘A` — Показать/скрыть секцию «Всегда скрытые»
  - `⌃⌥⌘R` — Аварийный сброс (возврат всех иконок на место)
- **Многоязычный интерфейс**:
  - Английский (English, по умолчанию)
  - Русский
  - Казахский (Қазақша)
  - Упрощенный китайский (简体中文)
  - Переключение языка на лету через меню в статус-баре без перезапуска приложения.
- **Безопасное завершение**: При выходе из приложения все разделители сбрасываются, поэтому ваши иконки никогда не останутся скрытыми.
- **Инструменты CLI и автоматизации**: Встроенные аргументы командной строки для сканирования и управления.
- **Воспроизводимая локальная подпись**: Скрипты создают сертификат в локальной связке ключей, благодаря чему разрешения macOS TCC (Accessibility и запись экрана) не сбрасываются после повторных сборок.

## Системные требования

- **macOS 14.0 (Sonoma)** или новее (протестировано на macOS 15 Sequoia, Apple Silicon и Intel).
- **Xcode 15.0+** и Command Line Tools.
- **[XcodeGen](https://github.com/yonaskolb/XcodeGen)** (`brew install xcodegen`).
- Платный аккаунт разработчика Apple не требуется: используется локальный самоподписанный сертификат.

## Установка

### Через Homebrew

```bash
brew tap reno09r/barkeep
brew install --cask barkeep
```

*Или одной командой:*
```bash
brew install reno09r/barkeep/barkeep
```

> **Примечание по Gatekeeper:** BarKeep подписан локальным сертификатом разработчика (чтобы оставаться бесплатным и открытым без платной подписки Apple за $99/год). Если macOS блокирует первый запуск, выполните в терминале команду `xattr -cr /Applications/BarKeep.app`, либо нажмите **«Всё равно открыть»** в **Системные настройки → Конфиденциальность и безопасность** (или правый клик по приложению в Finder → «Открыть»).

## Быстрый старт и сборка из исходников

Склонируйте репозиторий и соберите проект:

```bash
git clone https://github.com/Reno09r/BarKeep.git
cd BarKeep

# 1. Создать локальный сертификат подписи разработчика (только один раз)
make signing

# 2. Сгенерировать проект Xcode и скомпилировать
make gen
make build

# 3. Запустить BarKeep
make run
```

### Команды Makefile

| Команда | Описание |
|---|---|
| `make signing` | Настраивает сертификат подписи в связке ключей (`BarKeep Dev`) |
| `make gen` | Генерирует `BarKeep.xcodeproj` из `project.yml` |
| `make build` | Компилирует и подписывает Debug-сборку в каталоге `build/` |
| `make run` | Завершает старую версию и запускает свежесобранное приложение |
| `make stop` | Завершает BarKeep с возвратом всех иконок на место |
| `make logs` | Выводит лог в реальном времени (`~/Library/Logs/BarKeep.log`) |
| `make report` | Показывает последние записи диагностики |
| `make clean` | Удаляет артефакты сборки и сгенерированный проект Xcode |

## Настройка разрешений

При первом запуске BarKeep запросит два системных разрешения macOS:

1. **Универсальный доступ (Accessibility)**: Необходим для сканирования координат элементов меню-бара, чтения AX-дерева и отправки кликов.
2. **Запись экрана (Screen Recording)**: Необходима для получения снимков иконок для отображения в плавающей панели.

Как выдать разрешения:
1. Откройте **Системные настройки → Конфиденциальность и безопасность**.
2. Перейдите в **Универсальный доступ (Accessibility)** и включите тумблер для `BarKeep`.
3. Перейдите в **Запись экрана (Screen Recording)** и включите тумблер для `BarKeep`.
4. Перезапустите BarKeep.

> **Примечание**: Если запускать бинарник непосредственно из терминала, macOS может привязать разрешения к эмулятору терминала (Terminal, iTerm2, Kitty). Для проверки реального приложения используйте `open build/Build/Products/Debug/BarKeep.app`.

## Управление и горячие клавиши

| Действие | Управление |
|---|---|
| **Открыть/закрыть панель** | ЛКМ по иконке BarKeep |
| **Меню и настройки** | ПКМ или `⌃` + ЛКМ по иконке BarKeep |
| **Скрыть/показать скрытые** | `⌃⌥⌘H` |
| **Всегда скрытые** | `⌃⌥⌘A` |
| **Аварийный возврат иконок** | `⌃⌥⌘R` |

### Организация секций меню-бара

Структура строки меню BarKeep (справа налево):
`[Системные иконки] [BarKeep] [Видимые] | Разделитель скрытых | [Скрытые] | Разделитель всегда-скрытых | [Всегда скрытые]`

1. Разверните скрытые иконки нажатием `⌃⌥⌘H` или через панель.
2. Зажмите клавишу `⌘` и перетащите тонкую вертикальную черту разделителя влево или вправо, чтобы настроить границу видимости.
3. Либо удерживайте `⌘` и перетащите любую стороннюю иконку через разделитель.
4. Нажмите `⌃⌥⌘H`, чтобы скрыть секцию обратно.

## Настройка языка

По умолчанию используется английский язык. Вы можете переключить интерфейс в любой момент:

1. Нажмите правой кнопкой мыши по иконке BarKeep в строке меню.
2. Откройте подменю **Language** (Язык).
3. Выберите нужный язык:
   - **English** (по умолчанию)
   - **Русский**
   - **Қазақша**
   - **简体中文**

Все элементы меню, всплывающая панель, транслитерация поиска и диалоговые окна сразу же обновятся. Выбранный язык сохраняется в `UserDefaults` и применяется при каждом следующем запуске.

## CLI и автоматизация

Скомпилированное приложение поддерживает удобный CLI интерфейс для отладки и автоматизации:

```bash
# Вывести список всех элементов меню-бара (координаты, AX, PID, Bundle ID)
./build/Build/Products/Debug/BarKeep.app/Contents/MacOS/BarKeep --scan

# Активировать элемент по названию или window ID
./build/Build/Products/Debug/BarKeep.app/Contents/MacOS/BarKeep --press "Пункт управления"

# Отправка команд работающему экземпляру BarKeep
./build/Build/Products/Debug/BarKeep.app/Contents/MacOS/BarKeep --send showHidden
./build/Build/Products/Debug/BarKeep.app/Contents/MacOS/BarKeep --send hideHidden
./build/Build/Products/Debug/BarKeep.app/Contents/MacOS/BarKeep --send toggleHidden
./build/Build/Products/Debug/BarKeep.app/Contents/MacOS/BarKeep --send reset
./build/Build/Products/Debug/BarKeep.app/Contents/MacOS/BarKeep --send panel
./build/Build/Products/Debug/BarKeep.app/Contents/MacOS/BarKeep --send "activate:Telegram"
./build/Build/Products/Debug/BarKeep.app/Contents/MacOS/BarKeep --send quit
```

## Диагностика

- **Журнал событий**: `~/Library/Logs/BarKeep.log` или команда `make logs`.
- **Снимок состояния**: Правый клик по иконке BarKeep → «Скопировать отчёт в буфер».
- **Аварийный сброс**: Нажмите `⌃⌥⌘R` или выполните `BarKeep --send reset`, чтобы вернуть иконки.
- **Конфликты**: Не держите запущенными одновременно Ice, Bartender и BarKeep. Приложение автоматически предупреждает в меню при обнаружении другого менеджера.
