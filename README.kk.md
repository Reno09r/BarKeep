## Жоба туралы

**BarKeep** — бұл Bartender және Ice бағдарламаларының рухында жасалған macOS мәзір жолағына арналған ашық бастапқы кодты (open-source) менеджер. Ол мәзір жолағындағы артық белгішелерді экранның шетіне жасырады, қалқымалы панель арқылы жасырылған элементтерге жылдам қол жеткізуді қамтамасыз етеді, бірнеше тілде жылдам іздеуді қолдайды, меңзерді жақындатқанда белгішелерді автоматты түрде көрсетеді және төтенше пернелер тіркесімі арқылы барлық белгішелерді орнына қайтаруға мүмкіндік береді.

Қолданба толығымен **Swift, AppKit және SwiftUI** көмегімен бөгде кітапханаларсыз жазылған. Ice (GPL-3.0) бастапқы коды көшірілмеген; барлық логика нөлден бастап жобаланған және жүзеге асырылған.

## Мүмкіндіктер

- **Белгішелерді экран сыртына жасыру**: Бөлгіш элементті 10 000 px дейін созу арқылы оның сол жағындағы барлық белгішелер экран жиегінен тыс ысырылады.
- **Қалқымалы Bar Panel тақтасы** (BarKeep белгішесін *сол жақ батырмамен* басу): Жасырын белгішелердің нақты уақыттағы суреттерін және трекпад немесе тінтуір дөңгелегі арқылы көлденең айналдыруды қолдайтын заманауи HUD терезесі.
- **Көптілді іздеу**: Транслитерацияны қолдайтын жылдам іздеу жүйесі (мысалы, қазақша немесе орысша әріптермен теру латын атауындағы қолданбаларды табады). `Enter` батырмасы бірінші нәтижені ашады, `Esc` немесе тақтадан тыс басу оны жабады.
- **Жасырын белгішелерді белсендіру**: Тақтадағы белгішені басқан кезде тиісті мәзір жолағы бөлімі уақытша көрсетіледі, Accessibility API арқылы `AXPress` орындалады және бөлім қайтадан ұқыпты түрде жасырылады.
- **Меңзерді апарғанда көрсету**: Тінтуір меңзерін мәзір жолағының бос орнына апарғанда жасырын белгішелер бірден ашылады, ал меңзерді алшақтатқанда қайта жиналады.
- **Қолданбаларды басқарудың контекстік мәзірі**: Тақтадағы белгішені оң жақпен басу арқылы қолданбаны іске қосуға, жасыруға, жұмысын аяқтауға немесе мәжбүрлі түрде жабуға болады.
- **Жүйелік жылдам пернелер тіркесімдері**: Carbon `RegisterEventHotKey` арқылы жүзеге асырылған:
  - `⌃⌥⌘H` — «Жасырын» бөлімін көрсету/жасыру
  - `⌃⌥⌘A` — «Әрқашан жасырын» бөлімін көрсету/жасыру
  - `⌃⌥⌘R` — Апаттық қалпына келтіру (барлық белгішелерді қайтару)
- **Бірнеше тілді қолдау**:
  - Ағылшын тілі (English, әдепкі бойынша)
  - Орыс тілі (Русский)
  - Қазақ тілі (Қазақша)
  - Қытай тілі (简体中文)
  - Қолданбаны қайта іске қоспай-ақ, тілді мәзірден лезде өзгерту мүмкіндігі.
- **Қауіпсіз жабылу**: Қолданбадан шыққан кезде барлық бөлгіштер автоматты түрде бастапқы қалпына келеді, сондықтан белгішелеріңіз ешқашан жасырылған күйде қалмайды.
- **CLI және автоматтандыру**: Терминал арқылы сканерлеуге және басқаруға арналған пәрмендер.
- **Тұрақты жергілікті қолтаңба**: Скрипттер локальді кілттер тізбегінде тұрақты сертификат жасайды, бұл қайта құрастырған кезде macOS TCC рұқсаттарының (Accessibility және Screen Recording) сақталуын қамтамасыз етеді.

## Жүйелік талаптар

- **macOS 14.0 (Sonoma)** немесе одан жаңа нұсқа (macOS 15 Sequoia, Apple Silicon және Intel жүйелерінде тексерілген).
- **Xcode 15.0+** және Command Line Tools.
- **[XcodeGen](https://github.com/yonaskolb/XcodeGen)** (`brew install xcodegen`).
- Ақылы Apple әзірлеуші тіркелгісі талап етілмейді: жергілікті өздігінен қол қойылған сертификат қолданылады.

## Жылдам орнату және құрастыру

Репозиторийді жүктеп алып, жобаны құрастырыңыз:

```bash
git clone https://github.com/your-username/BarKeep.git
cd BarKeep

# 1. Жергілікті қолтаңба сертификатын жасау (тек бір рет)
make signing

# 2. Xcode жобасын жасау және құрастыру
make gen
make build

# 3. BarKeep қолданбасын іске қосу
make run
```

### Makefile негізгі пәрмендері

| Пәрмен | Сипаттамасы |
|---|---|
| `make signing` | Кілттер тізбегінде қолтаңба сертификатын баптайды (`BarKeep Dev`) |
| `make gen` | `project.yml` файлынан `BarKeep.xcodeproj` жобасын жасайды |
| `make build` | `build/` каталогында Debug нұсқасын жинайды және қол қояды |
| `make run` | Қолданбаның ескі данасын тоқтатып, жаңасын іске қосады |
| `make stop` | Қолданбаны тоқтатып, барлық белгішелерді қалпына келтіреді |
| `make logs` | Логтарды нақты уақыт режімінде көрсетеді (`~/Library/Logs/BarKeep.log`) |
| `make report` | Соңғы диагностикалық есепті шығарады |
| `make clean` | Жиналған файлдарды және жасалған Xcode жобасын өшіреді |

## Рұқсаттарды баптау

BarKeep алғаш іске қосылған кезде macOS жүйесінің екі рұқсатын сұрайды:

1. **Accessibility (Арнайы мүмкіндіктер)**: Мәзір жолағының координаттарын анықтау, элементтер ағашын оқу және шертулерді жіберу үшін қажет.
2. **Screen Recording (Экранды жазу)**: Панельде көрсету үшін жасырын белгішелердің суреттерін түсіруге қажет.

Рұқсат беру жолы:
1. **Жүйелік баптаулар → Құпиялылық және қауіпсіздік** бөлімін ашыңыз.
2. **Accessibility** бөліміне өтіп, `BarKeep` үшін ауыстырып-қосқышты қосыңыз.
3. **Экранды жазу** бөліміне өтіп, `BarKeep` үшін ауыстырып-қосқышты қосыңыз.
4. BarKeep бағдарламасын қайта іске қосыңыз.

## Басқару және жылдам пернелер

| Әрекет | Басқару |
|---|---|
| **Тақтаны ашу/жабу** | BarKeep белгішесін сол жақпен басу |
| **Мәзір және баптаулар** | BarKeep белгішесін оң жақпен немесе `⌃` + сол жақпен басу |
| **Жасырын белгішелерді ауыстырып-қосу** | `⌃⌥⌘H` |
| **Әрқашан жасырын** | `⌃⌥⌘A` |
| **Белгішелерді апаттық қалпына келтіру** | `⌃⌥⌘R` |

### Мәзір жолағының бөлімдерін баптау

BarKeep бөлімдерінің орналасу реті (оңнан солға):
`[Жүйелік] [BarKeep] [Көрінетін] | Жасырын бөлгіші | [Жасырын] | Әрқашан жасырын бөлгіші | [Әрқашан жасырын]`

1. `⌃⌥⌘H` арқылы немесе тақтадан жасырын белгішелерді көрсетіңіз.
2. `⌘` пернесін басып тұрып, шекараны реттеу үшін мәзір жолағындағы тік бөлгіш сызықты солға немесе оңға сүйреңіз.
3. Сонымен қатар, кез келген белгішені `⌘` пернесі арқылы бөлгіштің арғы жағына жылжытуға болады.
4. Бөлімді қайта жинау үшін `⌃⌥⌘H` пернелерін қайта басыңыз.

## Тілді баптау

Әдепкі тіл — ағылшын тілі. Тілді кез келген уақытта ауыстыруға болады:

1. Мәзір жолағындағы BarKeep белгішесін оң жақпен басыңыз.
2. **Language** (Тіл) мәзіршесіне өтіңіз.
3. Қажетті тілді таңдаңыз:
   - **English** (әдепкі)
   - **Русский**
   - **Қазақша**
   - **简体中文**

Интерфейс, тақта жазулары, іздеу жүйесі және ескерту терезелері бірден жаңарады. Таңдалған тіл `UserDefaults` жүйесінде сақталады және келесі іске қосылуларда қолданылады.

## Терминал (CLI) және автоматтандыру

```bash
# Барлық мәзір белгішелерін сканерлеу (координаттар, AX, PID, Bundle ID)
./build/Build/Products/Debug/BarKeep.app/Contents/MacOS/BarKeep --scan

# Белгішені аты бойынша белсендіру
./build/Build/Products/Debug/BarKeep.app/Contents/MacOS/BarKeep --press "Басқару орталығы"

# Қолданбаға пәрмен жіберу
./build/Build/Products/Debug/BarKeep.app/Contents/MacOS/BarKeep --send showHidden
./build/Build/Products/Debug/BarKeep.app/Contents/MacOS/BarKeep --send hideHidden
./build/Build/Products/Debug/BarKeep.app/Contents/MacOS/BarKeep --send toggleHidden
./build/Build/Products/Debug/BarKeep.app/Contents/MacOS/BarKeep --send reset
./build/Build/Products/Debug/BarKeep.app/Contents/MacOS/BarKeep --send panel
./build/Build/Products/Debug/BarKeep.app/Contents/MacOS/BarKeep --send "activate:Telegram"
./build/Build/Products/Debug/BarKeep.app/Contents/MacOS/BarKeep --send quit
```

## Диагностика

- **Жүйелік лог**: `~/Library/Logs/BarKeep.log` немесе `make logs` пәрмені.
- **Диагностикалық есеп**: BarKeep белгішесін оң жақпен басып → «Есепті алмасу буферіне көшіру».
- **Апаттық қалпына келтіру**: Барлық белгішелерді қайтару үшін `⌃⌥⌘R` пернелерін басыңыз немесе `BarKeep --send reset` орындаңыз.
